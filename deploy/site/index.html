LocalDex

삼성 휴대전화에서 DeX를 케이블이나 컴퓨터 없이 실행하고 조작할 수 있습니다.

Android APK

버전 0.1.0

APK 다운로드

One UI 8 이상인 삼성 기기와 Android 11 이상이 필요합니다. 파일 크기는 약 24 MB입니다.

설치 방법

  1. 삼성 휴대전화에서 APK를 다운로드하고 설치합니다.
  2. 설치 허용 안내가 나타나면 APK를 연 앱에 설치 권한을 부여합니다.
  3. 개발자 옵션을 켠 다음, LocalDex의 안내에 따라 무선 디버깅을 페어링합니다.
  4. 화면 사양을 선택하고 Start DeX를 누릅니다.
