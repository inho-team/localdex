LocalDex

삼성 휴대전화에서 DeX를 케이블이나 컴퓨터 없이 실행하고 조작할 수 있습니다.

Android APK

버전 0.1.0

APK 다운로드

One UI 8 이상인 삼성 기기, Android 11 이상, Wi-Fi 연결이 필요합니다. 파일 크기는 약 24 MB입니다.

설치 방법

  1. 삼성 휴대전화에서 APK를 다운로드하고 설치합니다.
  2. 설치 허용 안내가 나타나면 APK를 연 앱에 설치 권한을 부여합니다.
  3. 개발자 옵션을 켠 다음, 무선 디버깅을 페어링합니다.
    1. 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드 번호를 7번 누릅니다. 개발자 옵션이 이미 보인다면 이 과정은 건너뜁니다.
    2. LocalDex에서 알림을 허용하고 Start Pairing을 누릅니다.
    3. 열린 개발자 옵션 → 무선 디버깅에서 무선 디버깅을 켭니다. 네트워크 허용 창이 나타나면 허용합니다.
    4. 무선 디버깅 글자를 눌러 상세 화면을 연 뒤, 페어링 코드로 기기 페어링을 누릅니다.
    5. 코드 창을 열어 둔 채 알림창을 내립니다. LocalDex 알림을 펼쳐 Reply를 누르고 표시된 숫자 6자리를 입력합니다.
  4. 화면 사양을 선택하고 Start DeX를 누릅니다.
